## Finding: the engine clock error

Writing the proof of `US-090` showed that `TimeAwareRouter` floors the departure to a forecast step and the engine then checks each road at that floored time plus the elapsed time. The 600 s margin shrank by the gap to the step (up to 900 s). The lead confirmed it in `TimeAwareRouter.java:86` and `TimeAwareDijkstra.java:94`. The proof of 2026-10-07 walked from the same floored time, so it could not see it. Fixed as `US-096` (`66c9883`, `88c151c`): `StickyClosure` keeps the window start and the departure apart. 129 Java tests pass on GitHub Actions. The server image is rebuilt at the next rollout, and the flag is off at rest. Blocker [[BL-026-sticky-closure-clock-anchored-at-floored-departure|sticky-closure-clock-anchored-at-floored-departure]] is `monitoring`.
