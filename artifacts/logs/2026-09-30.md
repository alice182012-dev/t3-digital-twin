## New story US-058: the second tapped point fills From

The user described a tap-only flow: open the map, tap a point, click the arrow in its popup so it becomes the destination, then tap another point so it becomes the start. The story is [[EP-05-mockup-screen-coverage|mockup-screen-coverage]] Story 5, in Sprint 3 as P2 and size S, and it is not started. The user decided these rules over three answers:

1. The tap itself fills From, with no arrow click.
2. The popup still opens on that tap, with the depth and the arrow, so the user sees the current depth.
3. Clicking the arrow on that point moves it to To, replaces the old destination, and empties From. A route from a point to itself never occurs.
4. With both points empty or both set, a tap and the arrow behave as in `US-023`.

Today `destinationForPlace` in `floodmap/graphhopper-maps/src/floodmap/routeToPlace.ts` always moves the last query point, so a second tap on an empty From replaces the destination.
